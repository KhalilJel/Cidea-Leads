# Cidea Website Build SOP v1

This document records the repeatable process used while building Cidea's own digital assets.

## Phase 1 — Research
- Commercial keyword research
- Norwegian + international search intent
- Competitor and market review
- Identify high-value customer questions

## Phase 2 — Positioning
- Define target customer
- Define core problem
- Define desired outcome
- Define primary offer
- Define conversion path

## Phase 3 — Architecture
- Sitemap
- Page hierarchy
- URL structure
- Norwegian / English structure
- Blog and content architecture

## Phase 4 — Design
- Shared Cidea design foundation
- Distinct company visual identity
- Typography
- Spacing
- Components
- Motion
- Responsive behavior

## Phase 5 — Build
- Homepage
- Core service pages
- Navigation
- Language switching
- Forms and CTAs
- SEO foundations

## Phase 6 — Content
- High-value blog topics
- Internal linking
- Social content repurposing

## Phase 7 — Launch
- QA
- Analytics
- Search indexing
- Domain connection
- Performance review

## Phase 8 — Learn
Record what worked, what failed, conversion data, SEO results and reusable improvements.

The SOP evolves as the Cidea assets are built.
